# Paso 1 · Qué es un computador y cómo "piensa"

## La idea

Un computador es una máquina que recibe algo, hace algo con eso y devuelve algo. Siempre sigue tres pasos:

**ENTRADA → PROCESO → SALIDA**

- **Entrada:** lo que le das (tocar la pantalla, escribir, una foto).
- **Proceso:** lo que hace con eso (calcular, comparar, guardar).
- **Salida:** lo que te devuelve (un resultado en pantalla, un sonido, una imagen).

Ejemplo: una calculadora.
Entrada: tú escribes `6 × 7`. Proceso: multiplica. Salida: muestra `42`.

En tu app de Misiones pasa lo mismo. Entrada: tocas "Cama Maestra". Proceso: la app guarda la misión y suma XP. Salida: confeti y el mensaje "+10 XP".

Esto es lo que en la Ruta del Tercero se llama un **sistema**: partes que trabajan juntas para lograr algo.

## Las partes de un computador

| Parte | Para qué sirve | Es como... |
|-------|----------------|------------|
| Procesador (CPU) | Hace los cálculos | El cerebro |
| Memoria (RAM) | Guarda lo que estás usando ahora | La mesa donde trabajas |
| Almacenamiento | Guarda las cosas para siempre | El armario |
| Pantalla, teclado, parlantes | Entrada y salida | Los ojos, las manos y la voz |

## Los 0 y los 1

El computador solo entiende dos cosas: **encendido (1)** y **apagado (0)**. Con muchos 1 y 0 juntos representa números, letras, fotos y música. A cada 0 o 1 se le llama **bit**.

Así se cuentan los números en binario:

| Número | Binario |
|--------|---------|
| 0 | 000 |
| 1 | 001 |
| 2 | 010 |
| 3 | 011 |
| 4 | 100 |
| 5 | 101 |
| 6 | 110 |
| 7 | 111 |

Cada lugar vale el doble del anterior: 1, 2, 4, 8... Por eso `101` es 4 + 0 + 1 = **5**.
