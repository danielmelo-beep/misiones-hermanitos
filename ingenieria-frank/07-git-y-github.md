# Paso 7 · Git: la partida guardada de tu código

## La idea

En un videojuego guardas la partida para volver a ese punto si algo sale mal. **Git** hace lo mismo con tu código: guarda **versiones** de tu trabajo, cada una con una nota de qué cambiaste. Si algo se rompe, puedes volver atrás.

Lo importante:

- **Repositorio (repo):** la carpeta de un proyecto con todo su historial.
- **Commit:** una partida guardada, con un mensaje corto que dice qué hiciste. Ejemplo: "Agrego la lista de mis cosas favoritas".
- **GitHub:** la página web donde se guardan los repositorios en internet. Aquí está guardada tu app de Misiones.

Los ingenieros de verdad usan Git todos los días. Aprenderlo temprano es una gran ventaja.

## Mira un historial real

Pídele a Daniel que te muestre el repositorio `misiones-hermanitos` en GitHub. Entra a la lista de commits: ahí está la historia de tu app, versión por versión, cada una con su mensaje.

## Tu primer commit (sin instalar nada)

Esto se hace **con Daniel**, desde la página de GitHub:

1. Entra al repositorio y abre la carpeta `ingenieria-frank/proyectos/01-mi-primera-pagina`.
2. Abre el archivo `index.html` y toca el lápiz para **editarlo**.
3. Cambia el título por tu nombre.
4. Abajo, en el recuadro del mensaje, escribe qué hiciste: "Pongo mi nombre en el título".
5. Toca el botón verde para **guardar el commit**.
6. Entra a **History** (historial) y busca tu commit. Ya quedó guardado para siempre, con tu mensaje.

## Ejercicios

1. Haz **tres commits** seguidos, uno por cada cambio pequeño (por ejemplo: cambiar el título, agregar una lista, agregar un botón).
2. Escribe los mensajes de tus commits como si se los explicaras a alguien que no estuvo contigo. Un buen mensaje es corto y claro.
3. Mira el historial y encuentra tu primer commit. ¿Qué cambió entre ese y el último?
